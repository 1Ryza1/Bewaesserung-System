# Bewaesserung-System

Zimmerpflanzen feuchtigkeit messen und automatisch gießen.

Wir brauchen
Feuchtigkeitssensor
Microcontroller
Ventil
Behälter
Schlauch
Lampe



Feuchtigkeitssensor erkennt, dass die pflanze gegossen werden muss, anhand der trockenden erde und gibt das Signal and den Microcontroller.
Der Controller öffnet das dazugehörige Ventil.

Wenn der Behälter fast leer ist, leuchtet eine Lampe um zu Signalisieren, dass wasser anchgefüllt werdne muss. Vielleicht auch per push nachricht per Telegrambot
