# Arduino-Bewaesserung mit Pumpenschutz

Oeffnet [bewaesserung_sicher.ino](bewaesserung_sicher.ino) mit der Arduino IDE.

- [Einrichtung und Grenzwerte](ANLEITUNG.md)
- [Pruefbericht](PRUEFUNG.txt)

Board: Arduino Uno. Display: SH1106 128x64 an 0x3C. Bibliothek: U8g2.

Der Sketch ergaenzt Stundenbudget, Sperrzeiten und laufende USB-Messwerte. Mindestens zehn Minuten Startpause sind beabsichtigt. Erfolgreich kompiliert und in 16 Simulationen geprueft; der Test an der echten Anlage und der Upload stehen noch aus.
